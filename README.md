## 📝 Описание / Description

Добро пожаловать в архив материалов, посвященных разработке под **J2ME (Java 2 Micro Edition)**. Этот репозиторий создан в рамках организации **USoft-History** с целью сохранения исторического наследия мобильной разработки начала 2000-х годов.

Здесь собраны статьи, руководства, туториалы и справочные материалы, которые помогали программистам создавать легендарные игры и приложения для кнопочных телефонов (Siemens, Nokia, Sony Ericsson и др.).

---

## 📂 Структура репозитория / Structure

* `/articles` — основные текстовые материалы и статьи (в формате Markdown/HTML).
* `/tutorials` — пошаговые руководства по настройке среды (WTK, NetBeans, Eclipse) и созданию первых мидлетов.
* `/examples` *(если применимо)* — исходный код и примеры программ, рассматриваемых в статьях.
* `/media` — скриншоты, схемы и иллюстрации к материалам.

---

## 🛠️ Основные темы / Key Topics

В материалах репозитория рассматриваются следующие аспекты J2ME-разработки:
* **MIDP 1.0 / 2.0 & CLDC 1.0 / 1.1** — основы профилей и конфигураций.
* **Жизненный цикл мидлета** — методы `startApp()`, `pauseApp()`, `destroyApp()`.
* **Интерфейс пользователя** — работа с высокоуровневым (`Form`, `List`, `TextField`) и низкоуровневым (`Canvas`, `Graphics`) GUI.
* **Game API** — создание спрайтов (`Sprite`), слоев (`LayerManager`) и тайловых карт (`TiledLayer`).
* **Работа с памятью и хранилищем** — использование RMS (Record Management System).
* **Специфичные API вендоров** — Nokia UI API, Siemens API (работа с вибро, подсветкой, звуком).

## 🤝 Как внести свой вклад / Contributing

Если у вас сохранились редкие статьи, исходники старых уроков, журналы (например, *«Мобильные компьютеры»*, статьи с *Boomer.su*, *Siemens-Club*, *Java2me.ru*) или вы хотите исправить ошибки/опечатки в текущих текстах:

1. Сделайте **Fork** данного репозитория.
2. Создайте свою ветку (`git checkout -b feature/amazing-article`).
3. Внесите изменения и сделайте коммит (`git commit -m 'Добавлена статья о RMS'`).
4. Отправьте ветку в свой форк (`git push origin feature/amazing-article`).
5. Откройте **Pull Request**.
